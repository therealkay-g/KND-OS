01-PRD.md - KND OS & Kindu Search - Ce que fait le produit
Produits
2 produits séparés mais liés :
KND OS : logiciel caisse mobile + desktop pour commerçants
Kindu Search : PWA annuaire public type Google Maps pour Kindu
Kindu Search est intégré comme onglet dans KND OS (le commerçant voit son commerce comme le client)
Utilisateurs
Client chercheur (habitant Kindu)
Commerçant (pharmacien, boutiquier, quincaillier)
Admin Kay (vérifie à moto)
KND OS - Fonctions V1
Commun aux 3 modes
Auth OTP WhatsApp/SMS, pas d'email
100% offline-first, sync le soir
Scan code-barres via caméra téléphone
Impression ticket Bluetooth 58mm
Vente cash / crédit
Gestion dette client (Crédit Maman Georgette)
Bénéfice du jour en 1 clic (vente - achat)
Alertes stock faible
Mode Magasin
Vente rapide 3 clics : tap produit > panier > Vendre
Produits : nom, code-barres, prix_achat, prix_vente, stock, unité
Gestion dettes + encaissement dette
Mode Pharmacie
Champs : date_peremption, molécule, ordonnance_requise, photo_ordonnance
Alerte péremption : <30j rouge, <60j orange
Recherche par nom + molécule
Blocage si ordonnance requise et photo manquante
Liste produits expirant bientôt
Mode Quincaillerie
Unités complexes : SAC, BARRE 12m, KG, METRE, ROULEAU, PIECE
Quantité décimale : 2.5m, 0.5 sac
Affichage : 12.5 kg, 45 sacs (2250kg), 30 barres (360m)
Devis chantier auto : Chambre 4x4, Maison 2 chambres, Latrine, Dalle
Conversion devis -> vente
Kindu Search - Fonctions V1
Recherche
Recherche texte par nom produit / nom commerce
Filtre commune : Kasuku, Alunguli, Mikelenge
Filtre catégorie : Pharmacie, Quincaillerie, Alimentation, Resto, Hôtel, Salon, Location, etc.
Vue type Google Maps pour Kindu
Carte / Liste
Fiche commerce
Nom, catégorie, commune, adresse, horaires, WhatsApp, tel, lat/lng
Photos (1-5)
Badge "Stock Vérifié Live" vert si KND OS Pro + MAJ <24h
Sinon "Stock d'il y a X jours"
Boutons : WhatsApp direct, Appeler, Itinéraire
Clics comptés (vues, clics WhatsApp)
Don

Page don avec Mobile Money / Airtel Money
Montant libre ou paliers fixes
Fonctions reportées V2
